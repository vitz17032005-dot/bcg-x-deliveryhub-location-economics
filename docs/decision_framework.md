# Decision Framework

The model separates observed facts from decision assumptions.

**Observed:** job postings, stated/estimated salaries in the source, locations, dates, India city salary history and public FX observations.

**Derived:** role-family classification, annualized salary, USD normalization, posting counts, score components and final ranking.

**Not modeled as facts:** internal FTE capacity, transition cost, client constraints, security requirements, attrition, ramp time or profitability.

Recommended management workflow: shortlist from public market evidence → validate internal capacity and client constraints → run scenario economics using internal finance data → approve hub action.
