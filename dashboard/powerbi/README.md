# Power BI Build Specification

Load:
- `location_economics_scorecard.csv`
- `location_role_market_economics.csv`
- `india_city_salary_panel.csv`

Recommended pages:
1. **Location Scorecard** — cost/demand/FX score decomposition.
2. **Role Economics** — role × country demand and salary.
3. **India City Lens** — salary trend and tier comparisons.
4. **FX & Sensitivity** — currency stability and USD-normalized compensation.

Clearly label the score as a market-based relative index, not an internal margin forecast.
